## 结果与限制

- **已观察：** Linux 镜像目录、下载进度和取消控件、取消后保留部分文件并出现恢复入口、缓存镜像“使用”入口、远端 URL 失败后的重试入口、空间不足拒绝提示。
- **成功下载证据：** 本机缓存中的 `plasma` 文件经 `file` 识别为可启动 ISO 9660（卷标 `MANJARO_KDE_2610`）；测试机 `machine.toml` 的 `[boot] iso` 指向该缓存文件。因此成功介质来自真实 ISO 文件，未启动客体。
- **续传限制：** AlmaLinux 的部分下载从约 1.23 GiB 继续增长到 1.34 GB，但上游 HTTP/2 流之后返回 `PROTOCOL_ERROR`。这验证了恢复尝试和 Range 后追加写入；不能据此声称该镜像续传最终成功。
- **校验限制：** 已有测试截图没有形成可清晰复核的“校验成功”界面证据。本记录不宣称 UI 校验成功；下载器的 checksum、Range、取消和空间不足测试须以代码测试结果单独报告。
- **客体验收：** 未启动 QEMU guest，未验证安装器启动、桌面显示或客体安装完成。
- **发行版选择 UX：** osinfo-db 目录按单个安装介质逐行平铺，真实数据会产生很长的发行版/版本/变体列表。需要改成有层级的浏览：先按发行版分类，再选择发行版与版本/安装介质；保留架构、Live/Installer 和大小信息。这是产品 UX 待改进项，不是本截图批次已完成的工作。

## 可复现证据来源

- 原始 UI 截图由 Jin 在真实 Xfce `:20` 桌面逐步操作产生；本轮补查确认同一工作树的 inua-vm 也在 Inua/Hyprland Wayland 桌面运行。
- 测试机：`jin-iso-test`，仅用于 UI 流程；无客体启动。
- ISO 目录/下载实现：`internal/vm/isocatalog.go`、`internal/vm/isodownload.go`。
- UI 接线：`internal/vmui/service.go`、`internal/vmui/window.go`、`ui/vm.blp`、`ui/vm.ui`。
- 测试命令记录见 Goal 运行记录；此文档只陈述截图和文件系统可独立复核的观察。

截图经过去除桌面顶栏/底栏、遮挡测试机器标签和本机绝对路径处理；它们是功能验收证据，不代表原图或发行版页面内容完整。
